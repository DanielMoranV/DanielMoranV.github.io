# DanielMoranV.github.io

Sitio personal, servido automáticamente por GitHub Pages en
**<https://danielmoranv.github.io/>**.

> GitHub reserva el nombre `<usuario>.github.io`: cualquier repositorio que se llame así se
> publica como el sitio personal del usuario. No es un repositorio normal.

Hoy contiene una página mínima de presentación con los productos en producción y los
repositorios públicos. Es provisional: la landing definitiva vive en `djasoft.net.pe`,
desplegada en Cloudflare Pages. Cuando esté lista, esta página pasará a redirigir allí.

## Historial

Entre septiembre de 2022 y agosto de 2026 este repositorio alojó una versión de pruebas de la
web de **CONERI**, que quedó obsoleta. El sitio de CONERI vive en su propio repositorio y está
publicado en **<https://coneri.pe/>**.

## Estructura

Una sola página estática, sin dependencias ni proceso de build: `index.html` con los estilos
incrustados. Se adapta a tema claro y oscuro según la preferencia del sistema.
